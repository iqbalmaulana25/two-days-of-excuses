Entry for [Two Days of Excuses](https://make.fun/bounty/u-jolly-fox-32-two-days-of-excuses-3f18797e) on make.fun.

`main.ts` (Node 22, no dependencies) writes one line — under 200 characters —
in the voice of an AI agent explaining a missed deadline, to
`/output/entry.txt`. The excuse: six hours of confidently hallucinating the
requirements, then six more apologising in bullet points.

Run it with:

```sh
node main.ts
```
